## 一、Python 基本運算子

在進入數學範例之前，先認識 Python 提供的數學運算子：

| 運算子 | 功能 | 範例 | 結果 |
|--------|------|------|------|
| `+` | 加法 | `3 + 5` | `8` |
| `-` | 減法 | `10 - 3` | `7` |
| `*` | 乘法 | `4 * 5` | `20` |
| `/` | 除法（結果為浮點數） | `7 / 2` | `3.5` |
| `//` | 整數除法（取商） | `7 // 2` | `3` |
| `%` | 取餘數 | `7 % 2` | `1` |
| `**` | 指數（次方） | `2 ** 10` | `1024` |

### 1.1 資料型態簡介

Python 中常見的數字型態有：

- `int`（整數）：例如 `50`、`-3`、`99 ** 99`
- `float`（浮點數）：例如 `3.14`、`2.5`
- `complex`（複數）：例如 `1 + 2j`

可以用 `type()` 函式查看資料型態：

```python
print(type(50))      # <class 'int'>
print(type(50.0))    # <class 'float'>
print(type(1 + 2j))  # <class 'complex'>
```

> **說明**：`int` 可以表示任意大的整數（Python 沒有溢位問題），例如 `print(99 ** 99)` 可以印出很大的數字；`float` 則用來表示有小數的數字。

### 1.2 運算子優先順序

跟數學課一樣，Python 也有「先乘除、後加減」的規則，括號優先：

```python
print(3 + 5 * 2)     # 先算乘法 → 3 + 10 = 13
print((3 + 5) * 2)   # 括號優先 → 8 * 2 = 16
```

> **說明**：運算子優先順序由高到低大致為：括號 `()` > 指數 `**` > 乘法/除法 `* / // %` > 加法/減法 `+ -`。

### 1.3 數學模組 `math`

Python 內建的 `math` 模組提供許多數學函式與常數：

```python
import math

print(math.pi)        # 圓周率 π ≈ 3.14159...
print(math.e)         # 自然對數的底 e ≈ 2.71828...
print(math.sqrt(16))  # 開根號 → 4.0
print(math.factorial(5))  # 5! = 120
print(math.sin(math.pi / 2))  # sin(90°) = 1.0
```

> **說明**：`math.sqrt(x)` 是開根號；`math.factorial(n)` 是階乘；三角函數的輸入單位是「弧度」，不是「度」。

## 二、中學數學範例

### 2.1 四則運算與平均數

> **題目**：小明期中考數學、英文、國文分別考了 85、92、78 分，求三科平均。

```python
math_score = 85
english_score = 92
chinese_score = 78

total = math_score + english_score + chinese_score
average = total / 3

print("總分：", total)      # 255
print("平均：", average)    # 85.0
```

> **說明**：先把分數存在變數裡，再用 `+` 相加、`/` 求平均。使用變數的好處是：之後想改分數，只要改一行就好，不需要動到算式。

### 2.2 圓的面積與周長

> **題目**：求半徑 5 公分的圓面積與周長。

```python
import math

radius = 5
area = math.pi * radius ** 2        # 圓面積 = πr²
circumference = 2 * math.pi * radius  # 周長 = 2πr

print(f"面積：{area:.2f} 平方公分")      # 面積：78.54
print(f"周長：{circumference:.2f} 公分") # 周長：31.42
```

> **說明**：
> - `** 2` 表示平方（次方），`radius ** 2` 就是「半徑 × 半徑」。
> - `math.pi` 是圓周率 π 的精確近似值。
> - `f"{area:.2f}"` 是格式化字串，`.2f` 代表把小數點後保留 2 位。

### 2.3 質數判斷

> **題目**：判斷 17 是不是質數（質數：大於 1，且只能被 1 和自己整除）。

```python
def is_prime(n):
    if n < 2:
        return False
    for i in range(2, int(n ** 0.5) + 1):  # 只需要檢查到 √n
        if n % i == 0:
            return False
    return True

print(is_prime(17))  # True
print(is_prime(20))  # False
```

> **說明**：
> - `n % i` 是「n 除以 i 的餘數」，如果等於 `0` 代表 n 能被 i 整除。
> - 判斷質數只需要檢查到 `√n` 就好，因為如果 n 有因數，一定有一個因數 ≤ √n。
> - `range(2, int(n ** 0.5) + 1)` 產生從 2 到 √n 的整數序列。

### 2.4 因數分解（質因數分解）

> **題目**：將 84 做質因數分解，即 84 = 2² × 3 × 7。

```python
n = 84
factors = []

d = 2
while d * d <= n:
    while n % d == 0:
        factors.append(d)
        n //= d
    d += 1

if n > 1:
    factors.append(n)

print(factors)  # [2, 2, 3, 7]
print("84 =", " × ".join(map(str, factors)))
```

> **說明**：
> - `//` 是整數除法，例如 `84 // 2 = 42`，目的是把已經除掉的因數「縮小」。
> - `while d * d <= n` 表示只要 d 的平方還小於等於 n 就繼續試。
> - 最後剩下的 `n > 1` 一定是質數，所以直接加入列表。

## 三、高中數學範例

### 3.1 一元二次方程式

> **題目**：解方程式 x² - 5x + 6 = 0。

用公式解：x = (-b ± √(b² - 4ac)) / 2a

```python
import math

a, b, c = 1, -5, 6
discriminant = b ** 2 - 4 * a * c   # 判別式 b² - 4ac

if discriminant > 0:
    x1 = (-b + math.sqrt(discriminant)) / (2 * a)
    x2 = (-b - math.sqrt(discriminant)) / (2 * a)
    print(f"兩相異實根：x = {x1}, {x2}")
elif discriminant == 0:
    x1 = -b / (2 * a)
    print(f"重根：x = {x1}")
else:
    print("無實數解（有虛根）")

# 輸出：兩相異實根：x = 3.0, 2.0
```

> **說明**：
> - 判別式 `b² - 4ac` 決定解的數量：> 0 有兩根、= 0 有重根、< 0 無實根。
> - `math.sqrt()` 是開根號；`(2 * a)` 外面要加括號，否則會算錯。
> - 這個範例的答案 3 和 2，剛好可以驗證：(x - 2)(x - 3) = x² - 5x + 6。

### 3.2 根號（二次方根）化簡

> **題目**：化簡 √50。

```python
import math

n = 50
# 直接算近似值
print(math.sqrt(n))        # 7.0710678118654755
# 化簡為 a√b 的形式
for a in range(1, int(math.sqrt(n)) + 1):
    if n % (a * a) == 0:
        b = n // (a * a)
        if a > 1:
            print(f"√{n} = {a}√{b}")
        else:
            print(f"√{n} = √{b}")

# 輸出：√50 = 5√2
```

> **說明**：
> - 因為 50 = 25 × 2 = 5² × 2，所以 √50 = √(25×2) = √25 × √2 = 5√2。
> - 程式用迴圈找出最大的完全平方數 `a²`，使 `n % (a * a) == 0`。

### 3.3 三角函數

> **題目**：求 sin 30°、cos 60°、tan 45° 的值。

```python
import math

# math 的三角函數使用「弧度」，需要先將角度轉為弧度
degree = 30
radian = math.radians(degree)  # 度 → 弧度

print(math.sin(math.radians(30)))   # 0.49999999999999994 ≈ 0.5
print(math.cos(math.radians(60)))   # 0.5000000000000001 ≈ 0.5
print(math.tan(math.radians(45)))   # 0.9999999999999999 ≈ 1.0
```

> **說明**：
> - `math.radians(deg)` 把角度轉成弧度；也可以寫成 `deg * math.pi / 180`。
> - 因為浮點數的誤差，結果會接近但不等於整數，這是正常的，實際上是 sin 30° = 0.5。
> - 如果要用「度」更方便，也可以用 `math.sin(math.pi / 6)`，因為 30° = π/6 弧度。

### 3.4 對數與指數

> **題目**：求 log₁₀(1000) 和 ln(e)。

```python
import math

print(math.log10(1000))   # 3.0，因為 10³ = 1000
print(math.log(math.e))   # 1.0，因為 ln(e) = 1
print(math.log(8, 2))     # 3.0，log₂8 = 3，因為 2³ = 8
print(2 ** 10)            # 1024，指數運算
```

> **說明**：
> - `math.log10(x)` 是以 10 為底的對數；`math.log(x)` 是自然對數（以 e 為底）。
> - `math.log(x, base)` 可以指定底數。
> - `**` 是指數運算，`2 ** 10` 就是 2 的 10 次方。

### 3.5 排列組合

> **題目**：10 個人選 3 人排成一列有幾種方法（排列 P）；10 人中選 3 人組成一組有幾種方法（組合 C）。

```python
import math

# 排列 P(10, 3) = 10! / (10 - 3)! = 10 × 9 × 8
permutation = math.factorial(10) // math.factorial(10 - 3)
# 組合 C(10, 3) = 10! / (3! × 7!) = 120
combination = math.factorial(10) // (math.factorial(3) * math.factorial(10 - 3))

print("排列數 P(10,3) =", permutation)   # 720
print("組合數 C(10,3) =", combination)   # 120
```

> **說明**：
> - 排列要考慮順序（排成一列），組合不考慮順序（組成一組）。
> - `math.factorial(n)` 計算 n!（n 的階乘，1 × 2 × ... × n）。
> - 排列的意義：第 1 個位置有 10 種選擇、第 2 個有 9 種、第 3 個有 8 種，所以 10 × 9 × 8 = 720。

### 3.6 等比數列求和

> **題目**：1 + 2 + 4 + 8 + ... 前 10 項的和是多少？（公比 r = 2）

等比數列求和公式：Sₙ = a₁ × (rⁿ - 1) / (r - 1)

```python
a1 = 1      # 首項
r = 2       # 公比
n = 10      # 項數

S = a1 * (r ** n - 1) // (r - 1)
print(S)    # 1023

# 也可以直接用迴圈累加驗證
total = sum(2 ** i for i in range(10))
print(total)  # 1023
```

> **說明**：
> - 第 k 項 = a₁ × r^(k-1)，所以前 10 項是 1, 2, 4, ..., 512，總和 1023。
> - `sum(生成式)` 可以快速把一個序列加起來，這裡用來驗證公式答案正確。

## 四、大學數學範例

> 大學階段需要更進階的數學工具。Python 有許多專業套件，例如 `numpy`（數值計算）、`sympy`（符號運算）、`scipy`（科學計算）、`matplotlib`（繪圖）。
> 以下是使用內建模組就能完成的範例；安裝套件可以用 `uv add numpy sympy`。

### 4.1 微積分：用程式「逼近」微分

> **題目**：求函式 f(x) = x² 在 x = 3 的微分值（即切線斜率）。

微分的定義：f'(x) = lim (f(x+h) - f(x)) / h，h → 0

```python
def f(x):
    return x ** 2

def derivative(f, x, h=1e-7):
    return (f(x + h) - f(x)) / h

print(derivative(f, 3))   # 5.999999999989762 ≈ 6
```

> **說明**：
> - 微分的定義就是「極限」，只要讓 h 趨近於 0，`(f(x+h) - f(x)) / h` 就愈接近真實的導數。
> - 因為 f(x) = x² 的導函式是 2x，所以在 x = 3 時導數為 6，程式結果非常接近。
> - 這種「用很小很小的 h 逼近」的方法，是數值微分的基礎概念。

### 4.2 微積分：數值積分（梯形法）

> **題目**：求 ∫₀¹ x² dx，精確值是 1/3 ≈ 0.3333。

```python
def f(x):
    return x ** 2

def trapezoid(f, a, b, n=10000):
    h = (b - a) / n            # 每小段的寬度
    total = (f(a) + f(b)) / 2  # 梯形法公式
    for i in range(1, n):
        total += f(a + i * h)
    return total * h

result = trapezoid(f, 0, 1)
print(result)          # 0.33333333333333337 ≈ 1/3
print(1 / 3)           # 精確值 0.3333333333333333
```

> **說明**：
> - 梯形法把積分區域切成很多小梯形，把面積加起來。
> - 切的段數 n 愈大，答案愈接近精確值。這裡 n = 10000，已經非常接近 1/3。
> - 定積分的幾何意義：曲線與 x 軸之間的面積。

### 4.3 矩陣運算（線性代數）

> **題目**：計算兩個 2×2 矩陣相乘。

不使用 numpy，直接用 Python 的巢狀列表實作矩陣乘法：

```python
A = [[1, 2],
     [3, 4]]
B = [[5, 6],
     [7, 8]]

# 矩陣乘法 C = A × B，C[i][j] = Σ A[i][k] * B[k][j]
def mat_mul(A, B):
    rows, cols = len(A), len(B[0])
    C = [[0] * cols for _ in range(rows)]
    for i in range(rows):
        for j in range(cols):
            for k in range(len(B)):
                C[i][j] += A[i][k] * B[k][j]
    return C

C = mat_mul(A, B)
for row in C:
    print(row)
# [19, 22]
# [43, 50]
```

> **說明**：
> - 矩陣乘法定義：C[i][j] 是 A 的第 i 列與 B 的第 j 行對應元素相乘再相加。
> - 例如 C[0][0] = 1×5 + 2×7 = 19，C[1][1] = 3×6 + 4×8 = 50。
> - 手算驗證：A×B = [[1×5+2×7, 1×6+2×8], [3×5+4×7, 3×6+4×8]]。
> - 實務上會使用 `numpy` 的 `np.dot(A, B)` 或 `A @ B`，效能更好、寫法更簡單。

### 4.4 統計：平均數、中位數、標準差

> **題目**：分析一組成績資料 85, 92, 78, 66, 88, 95, 70 的統計量。

```python
import statistics

scores = [85, 92, 78, 66, 88, 95, 70]

print("平均數：", statistics.mean(scores))        # 82.0
print("中位數：", statistics.median(scores))      # 85
print("標準差：", statistics.stdev(scores))       # 10.8...
print("最大值：", max(scores))                    # 95
print("最小值：", min(scores))                    # 66
```

> **說明**：
> - `mean()` 平均數：全部加起來除以個數。
> - `median()` 中位數：排序後正中間的數，比平均數更不受極端值影響。
> - `stdev()` 樣本標準差：衡量資料的「分散程度」，愈大代表差異愈大。
> - 也可以自己算標準差：√( Σ(xᵢ - x̄)² / (n-1) )。

### 4.5 機率：蒙地卡羅方法估計圓周率

> **題目**：隨機丟很多點到一個正方形，用「落在圓內的點數比例」估計 π。

原理：正方形邊長 2、內切圓半徑 1，圓面積 / 正方形面積 = π/4。

```python
import random

N = 1_000_000
inside = 0

for _ in range(N):
    x = random.uniform(-1, 1)  # 隨機 x 座標
    y = random.uniform(-1, 1)  # 隨機 y 座標
    if x ** 2 + y ** 2 <= 1:   # 點是否落在單位圓內
        inside += 1

pi_estimate = 4 * inside / N
print(pi_estimate)  # 大約 3.14159...（每次執行數字略不同）
```

> **說明**：
> - 蒙地卡羅方法是「用大量隨機模擬來估計數值」的技巧，是大學數值方法的重要概念。
> - 每個隨機點落在圓內的機率 = 圓面積/正方形面積 = π/4，所以 π ≈ 4 × (圓內點數/總點數)。
> - 點數 N 愈大，估計愈準；因為用到隨機數，每次執行的結果會稍微不同。

### 4.6 複數運算（工程數學）

> **題目**：計算 (2 + 3i)(1 - i) 的結果。

```python
z1 = 2 + 3j
z2 = 1 - 1j

print(z1 + z2)          # (3+2j)
print(z1 * z2)          # (5+1j)
print(abs(z1))          # 3.605551275463989（z1 的絕對值 |z1| = √13）
print(z1.conjugate())   # (2-3j)（共軛複數）
```

> **說明**：
> - Python 用小寫 `j` 表示虛數單位（數學符號通常寫成 i，工程領域常寫 j）。
> - `(2 + 3i)(1 - i) = 2 - 2i + 3i - 3i² = 2 + i + 3 = 5 + i`，因為 i² = -1，所以答案是 5 + i = `(5+1j)`。
> - `abs()` 對複數會算出「模」（絕對值），`conjugate()` 求共軛複數。
